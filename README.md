# Wayfarer для WoW Circle 3.3.5a

Русская озвучка квестов Альянса и рассказов о местах, книг и надписей для Circle-клиента World of Warcraft 3.3.5a (build 12340). Сборка включает основной аддон и два обязательных голосовых пакета: Alliance и Narrator.

> Это адаптация Wayfarer для клиента WoW 3.3.5a. Она основана на оригинальном проекте [AndrewichLV/wayfarer-wow-forever](https://github.com/AndrewichLV/wayfarer-wow-forever), созданном для WoW Forever. Это отдельная сборка; она не является официальным проектом Blizzard.

## Авторы и развитие этой сборки

В истории изменений оригинального репозитория указаны **AndrewichLV** и **claude**. Благодарим авторов оригинального проекта и сохраняем ссылку на его исходную страницу: [GitHub — wayfarer-wow-forever](https://github.com/AndrewichLV/wayfarer-wow-forever).

Эта версия развивает и адаптирует проект для Circle 3.3.5a: использует клиентские API старого интерфейса, очередь и сегментное воспроизведение, синхронизирует субтитры и общий прогресс логической реплики, а также содержит исправления плеера и обработки очереди. Авторство оригинального кода, голосов и материалов остаётся за их правообладателями.
## Совместимость и состав

Сборка подготовлена для **WoW Circle 3.3.5a, build 12340**. Её нужно считать проверенной именно для этой среды; совместимость с другими сборками 3.3.5a не гарантируется.

В `Interface/AddOns` должны находиться все три каталога:

| Каталог | Назначение |
| --- | --- |
| `Wayfarer` | Основной аддон: обработка событий, очередь, обычный и сегментный движки, плеер, субтитры, настройки и диагностика. |
| `Wayfarer_Voices_Alliance` | Русские голосовые записи и индекс квестов/диалогов Альянса. |
| `Wayfarer_Voices_Narrator` | Голос рассказчика, индекс лора мест и озвучиваемых страниц книг и надписей. |

Голосовые каталоги зависят от `Wayfarer` и не работают отдельно. В этой сборке нет паков Horde, Shared Quests или Wayfarer Stories/радио. Озвучиваются только записи, присутствующие в установленных индексах; полного покрытия всех квестов и NPC не обещается.

## Установка

1. Полностью закройте игру.
2. Откройте папку клиента Circle и перейдите в `Interface/AddOns`.
3. Скопируйте туда каталоги `Wayfarer`, `Wayfarer_Voices_Alliance` и `Wayfarer_Voices_Narrator` из сборки. Не кладите папку `release-staging` или дополнительный общий каталог внутрь `AddOns`.
4. Проверьте структуру: например, файл должен находиться по пути `Interface/AddOns/Wayfarer/Wayfarer.toc`, а не `Interface/AddOns/Wayfarer/Wayfarer/Wayfarer.toc`.
5. Запустите игру заново. На экране выбора персонажа откройте список модификаций и убедитесь, что включены основной Wayfarer и оба голосовых пакета.
6. Войдите персонажем. Команда `/wf packs` должна показать обнаруженные пакеты. При замене или добавлении аудиофайлов перезапускайте клиент полностью: одного `/reload` может быть недостаточно для повторной загрузки звуков клиентом.

## Возможности

- Автоматическая озвучка доступных реплик принятия, выполнения и сдачи квестов Альянса.
- Озвучка доступных рассказов о зонах и подзонах, а также страниц поддерживаемых книг и надписей из пакета Narrator.
- Одна очередь для последовательного воспроизведения; квестовые реплики имеют приоритет над ожидающим лором.
- Обычное воспроизведение и сегментный режим. Сегментный режим сохраняет одну логическую реплику: субтитры и общий прогресс не сбрасываются на границах её аудиофрагментов.
- Плеер показывает имя NPC, название квеста или контекст реплики, текст при наличии данных, таймер и прогресс. Портрет отображается, если клиент и данные позволяют определить его; иначе используется предусмотренное изображение-заполнитель.
- Управление из плеера и командами: Pause/Resume, Skip и Stop. Кнопка скрытия прячет окно без изменения очереди; отдельный X очищает очередь и закрывает плеер, а плавающая кнопка возвращает скрытое окно.
- Настройки, журнал мест/атлас, повтор последней реплики и диагностические средства.

## Команды

Основные команды доступны через `/wf`, `/wayfarer` и старый псевдоним `/vru`. Вызов `/wf` без параметров показывает встроенную справку.

| Команда | Назначение |
| --- | --- |
| `/wf options` | Открыть настройки. |
| `/wf pause` | Переключить паузу/продолжение. |
| `/wf skip` | Пропустить текущую реплику по правилам аудиодвижка. |
| `/wf stop` | Очистить очередь и остановить дальнейшие запуски. |
| `/wf replay` | Повторить последнюю реплику, если она сохранена. |
| `/wf quest <ID> [a\|p\|c]` | Вручную найти и воспроизвести реплику квеста: принятие (`a`), прогресс (`p`) или завершение (`c`). |
| `/wf zone` | Повторно запросить озвучку текущего места, если для него есть запись. |
| `/wf journal` или `/wf j` | Открыть встроенный атлас мест; доступные рассказы зависят от Narrator и открытых данных персонажа. |
| `/wf packs` | Показать обнаруженные голосовые пакеты. |
| `/wf stats` | Показать статистику собранных аддоном текстов. |
| `/wf npc` | Показать данные о текущем собеседнике, известные аддону. |
| `/wf report [комментарий]` | Создать репорт о текущей или последней реплике. |
| `/wf reports` / `/wf reports clear` | Показать или очистить локальные репорты. |
| `/wf log` | Показать последние записи журнала событий. |
| `/wf reset seen` / `/wf reset zones` | Сбросить отметки прослушанных реплик или посещённых мест. |
| `/wf v3` / `/wf v4` | Выбрать модель голосов там, где индекс содержит соответствующие варианты; при отсутствии данных используется доступная запись. |
| `/wf mine [скорость]`, `/wf mine gaps [скорость]`, `/wf mine stop` | Сбор игровых текстов для разработки/пополнения данных; обычному игроку запускать не требуется. |
| `/wf testui [hide\|scale N]`, `/wf debugui` | Тест и диагностика интерфейса; команды для разработчика. |

Технические команды сегментного движка начинаются с `/wfseg`: `mode on|old`, `pause`, `resume`, `skip`, `stop`, `status`, `guard <сек>` и `playuid alliance|narrator <UID>`. `algorithm` и тестовая команда `play` относятся к разработческой проверке экспериментальных данных; тестовые индексы и аудио в этой сборке не поставляются, поэтому они не являются пользовательским способом выбора/прослушивания содержимого.

## Ограничения воспроизведения

Circle 3.3.5a запускает аудио через `PlaySoundFile`, но в проверенной сборке клиента недоступны `StopSound` и `C_Sound`. Поэтому аддон не может адресно оборвать уже запущенный OGG, перемотать его или продолжить с произвольной позиции.

- В сегментном режиме Pause отмечает паузу сразу, но текущий короткий фрагмент доигрывает; следующий фрагмент не запускается. Resume продолжает со следующего фрагмента.
- Skip и Stop отменяют логические продолжения и очищают ожидающую очередь, но уже запущенный физический фрагмент может завершиться сам. В обычном режиме целая реплика также может доиграть до расчётного конца.
- Таймер и прогресс рассчитываются по длительностям из индексов, а не по достоверному callback завершения аудио. Возможна небольшая погрешность относительно фактического звука.
- Портрет NPC не гарантируется для каждого персонажа: нужны доступный клиентский unit и подходящие данные. В остальных случаях показывается статичный fallback.

## Известные ограничения и диагностика

- Покрытие зависит от содержимого голосовых индексов; отсутствие записи не является ошибкой воспроизведения.
- Автоматическое сопоставление портрета зависит от NPC ID и доступности целевого персонажа через API клиента в момент реплики.
- `testui`, `debugui`, `/wfseg` и `mine` предназначены преимущественно для диагностики и разработки. Не включайте экспериментальные режимы без необходимости.
- При проблеме сначала проверьте `/wf packs`, затем `/wf log` и `/wf report`.
